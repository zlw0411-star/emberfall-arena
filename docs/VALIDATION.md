# 首版验证记录

2026-10-15，Windows / Node.js，浏览器 Canvas 2D。

## 当前成长规则

- 15级满级，在2、4、6、8、10、12、14、15级各选择一次，最多三个主动技能。选择时战斗与倒计时继续。
- 基础生命280、攻击13；每级增加8生命、恢复8生命、增加0.4基础攻击。15级基础生命392、攻击18.6，均为线性增长。
- 伤害强化每阶10%，最多50%；攻速与主动技能冷却保留下限，技能等级有上限。
- 地图晶体5经验，小怪15经验、巨兽25经验（35%直接获得、65%掉落晶体）；角色击杀经验为40＋被击败者等级×5，仅首次死亡结算。
- 经验阈值为round((65＋(当前等级－1)×12)×1.1)，1→15累计2204经验，维持原定8–12分钟目标。
- 第80秒起公屏提前10秒提醒开放互伤，第90秒正常解除保护。任意角色15级后停止刷怪与补充地图晶体，预警10秒后缩圈。

## 规则与地图回归

规则测试覆盖种子复现、空间索引与地图连通、90秒互伤保护、八个技能节点及跨级队列、属性线性增长与技能上限、角色击杀经验防重复、技能选择期间继续移动战斗、死亡清选择、冲刺碰墙、阶段伤害倍率、玩家与AI满级触发、决战停止刷新、缩圈与同帧平局、重新开始，以及公屏公告触发与暂停。

## 最终对局节奏

三个种子均由8名AI使用相同规则自动成长和选技。此组使用30Hz模拟时间步长，浏览器使用60Hz。

| 种子 | 首次15级 | 结束时间 | 结果 |
| --- | ---: | ---: | --- |
| sim-101 | 439.1秒 | 535.7秒（8.93分钟） | 正常结束 |
| sim-202 | 466.5秒 | 541.6秒（9.03分钟） | 正常结束 |
| sim-303 | 538.7秒 | 665.9秒（11.10分钟） | 正常结束 |

平均9.68分钟，3/3在8–12分钟范围；均进入满级决战，无决战后刷怪或地图晶体生成异常。随机地图、构筑和玩家操作会影响实际时长，这不是每局固定时限。

另以浏览器相同的60Hz完整复测 `sim-101`：435.7秒首次15级、554.6秒（9分15秒）结束，正常决出胜者，无模拟或生成异常。

## 性能与浏览器

- 8名AI＋52只存活怪物，60Hz，测量30秒模拟：平均0.787毫秒/步，p95为1.481毫秒/步，最大20.946毫秒，约21.18倍实时。测量为无绘制模拟，不代表渲染帧率；存在单次计算尖峰。
- 浏览器原生RAF绘制配合60Hz模拟和坐标插值，试玩预览中FPS约175–180。显示器刷新率、窗口状态和硬件影响实际帧率。
- 已查看宽屏和窄侧栏布局，实际验证开始、键盘移动、自动战斗、2级弹出选择且时间继续、按1选火球并按Q施放，以及暂停与继续。浏览器未发现脚本错误。
- 像素图形由程序绘制，不依赖外部图片或字体下载。
