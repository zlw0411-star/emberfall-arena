# 余烬试炼 · EMBERFALL

浏览器俯视角像素肉鸽竞技游戏。一个玩家与十一名 AI（共12人）同场成长，最后一名存活者获胜。

## 运行

需要 Node.js 22 或更新版本，无第三方依赖。

```powershell
npm start
```

打开 http://127.0.0.1:4173 。不要直接双击 index.html，原生 ES 模块需要 HTTP 服务。

## 玩法选择

主菜单选择「经典远程」或「近战刀战」，再点击开始。经典模式自动射击；近战模式中全部12名旅者持刀，鼠标定向、左键点击挥刀，按住连续斩击。近战技能为突进斩、旋风斩和重斩，配合刀锋、攻速、生命、拾取及刀势强化，靠走位与突进避险。刀击和刀技受到墙体遮挡，突进与击退不能穿墙，没有翻滚、格挡、弹反或无敌。

暂停、死亡与结算页面可返回主菜单切换玩法；重新开始沿用当前玩法，刷新页面默认经典远程。

近战三种刀技分别显示突进残影、环绕刀光和重斩蓄力，保留0.72–1.05秒的完整视觉与余效；动画不会额外延长动作锁或追加伤害。

## 操作

- WASD / 方向键移动。经典远程普攻自动寻找最近且视线可达的有效敌人；近战刀战使用鼠标定向、左键挥刀，按住连斩。
- 鼠标指向技能目标，Q / E / R 释放按学习顺序装备的主动技能。
- 2、4、6、8、10、12、14、15 级随机三选一，点击卡片或按 1 / 2 / 3 选择；选择期间仍能移动、攻击、释放已学技能，并可能受伤或死亡。
- 主动技能最多3个，已有主动技能仍可升级；每次升级增加生命和攻击。击败角色也会获得经验。
- Esc 暂停；失去窗口焦点或切换标签页也会暂停。
- 死亡后可以观战，通过右侧试炼者列表切换观察对象，或重开。

## 规则

单局通常5–10分钟，最长12分钟。8分40秒仍无人满级时自动开启同样的决战流程，留出完整的10秒预警、180秒缩圈和收尾；12分整最终风暴覆盖全图。如果届时仍有多人存活，将同时被风暴淘汰并判平局。

前90秒角色不能互伤，怪物和陷阱正常生效。第80秒起显示全场互伤预警与10秒倒计时。之后自由交战，争夺期旅者护甲较强，决战时减伤降低。任意角色达到最高15级立刻进入决战：停止新小怪与地图经验生成，现存资源保留；随机选定可达圆心，预警10秒后在180秒内收缩至零。圈外伤害随时间上升。最后一位存活者获胜；同帧全灭显示平局。

12个出生点均匀分布在遗迹外围。相比8人版本，怪物和地图晶体的初始数量、存量上限与补充速度提高约20%，兼顾争夺密度与单局发育时间。

## 验证

```powershell
npm test
npm run simulate
npm run duels
npm run melee-duels
npm run performance
```

`tests/simulate.js` 支持通过命令行传入种子。规则测试使用 Node 原生测试运行器；模拟无绘制，所有角色使用同一套 AI。地图随机、技能选择和对局可用相同种子复现。

在 PowerShell 使用 `$env:SIM_HZ='60'; node tests/simulate.js sim-101` 可按浏览器的60Hz时间步长完整复测一局。

使用 `$env:GAME_MODE='melee'; $env:SIM_HZ='60'; npm run simulate` 验证近战整局；performance同样读取GAME_MODE，默认classic。

浏览器使用60Hz固定模拟与画面插值，渲染自动跟随显示器刷新率（60/120/144Hz等），实际帧率显示在战场顶部。地形预绘制、空间索引碰撞、AI寻路缓存减少每帧开销。

模块接口和文件分工见 docs/CONTRACT.md。static dist 可直接部署到任意静态站点服务，Sites 配置位于 .openai/hosting.json。
