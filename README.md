# 余烬试炼 · EMBERFALL

浏览器俯视角像素肉鸽游戏。一个玩家与十一名 AI（共12人）同场成长，可选择生存竞技或首领竞伤。

接手开发请先阅读[详细交接文档](docs/HANDOFF.md)，其中包含当前规则、代码接口、测试、发布流程与已知限制。

了解项目从初版到当前玩法的变化，请阅读[游戏迭代历程与开发复盘](docs/EVOLUTION.md)，包括需求变化、体验反馈、重构修复和首领平衡试验。

最近一次本地修复包括复活输入、技能卡方向键、首领AI攻击窗口、前摇技能预测、静态小地图缓存和自动回归，详见[修复记录](docs/FIXES-20261022.md)。此前的竞技观战焦点、窄屏观战入口、小地图比例和多指针输入修复见[10月21日修复记录](docs/FIXES-20261021.md)。本地验证、源码同步与试玩站点部署分别记录在[VALIDATION.md](docs/VALIDATION.md)。

## 运行

需要 Node.js 22 或更新版本，无第三方依赖。

```powershell
npm start
```

打开 http://127.0.0.1:4173 。不要直接双击 index.html，原生 ES 模块需要 HTTP 服务。

## 玩法选择

主菜单选择「经典远程」「近战刀战」或「首领竞伤」，再点击开始。经典模式自动射击；近战模式中全部12名旅者持刀，鼠标定向、左键点击挥刀，按住连续斩击。每种武器都有13项技能（5主动、8被动），从随机三选一中构筑，最多装备3个主动。近战主动包括突进斩、旋风斩、重斩、穿云刺和护体刀阵，配合刀锋、攻速、生命、拾取及刀势强化，靠走位与突进避险。刀击和刀技受到墙体遮挡，突进与击退不能穿墙，没有翻滚、格挡、弹反或无敌。

暂停、死亡与结算页面可返回主菜单切换玩法；重新开始沿用当前玩法，刷新页面默认经典远程。

## 技能构筑

| 技能池 | 主动技能（五选三） | 被动强化 |
| --- | --- | --- |
| 经典远程 | 火球、震荡冲刺、震荡波、闪电链、冰霜新星 | 强力弹丸、迅捷、坚韧、拾荒者、连射、弱点洞察、战斗续航、灵能专注 |
| 近战刀战 | 突进斩、旋风斩、重斩、穿云刺、护体刀阵 | 刀锋强化、迅捷、坚韧、拾荒者、刀势延伸、弱点洞察、战斗续航、灵能专注 |

闪电链优先打向鼠标前方，再连跳附近敌人；冰霜新星伤害并减速周围敌人。穿云刺蓄力后沿锁定方向打出窄幅长刺；护体刀阵提供短时护盾，能吸收普通战斗与陷阱伤害，风暴会穿透。新刀技和两个新远程技能都检查障碍遮挡。弱点洞察最高25%概率造成1.5倍暴击，战斗续航每级击杀回血3点，灵能专注每级缩短主动冷却4%（最高20%）。技能重复选择强化、满级排除和连续升级的选择队列沿用原规则。

## 首领竞伤

主菜单新增「首领竞伤」，选择自己的远程或近战武器及主题地图；全场固定6远程、6近战。前90秒打怪探索，第85秒预告、第90秒余烬巨像登场。首领初始18万生命，有横扫、落石、十字震地与三个血量阶段，所有攻击带锁定位置的预警。中央为独立开阔战场，外围保留发育资源。

角色全程互不伤害，友方不阻挡弹丸。普攻、技能、暴击对首领实际造成的HP损失计分，溢出伤害和尾刀不额外加分；小怪仍可击杀获取经验但不计竞伤分。首领模式全部经验为竞技基础值的1.5倍：每10秒有效参战且结算时存活者获得6经验，地图晶体每颗7.5经验，普通小怪总经验22.5、巨兽37.5。探索和清怪仍是主要成长来源。15级后继续战斗与刷新资源，不缩圈。

倒下8秒复活，保留经验、等级、技能、冷却和累计伤害；原待选卡也保留，死亡不能重抽。重生后2秒保护，可移动但不能攻击。首领死亡或10分钟结算，累计伤害最高者获胜，同分并列；全员死亡仍继续，零伤害不产生冠军。侧栏显示即时伤害榜、武器、占比与死亡次数。

首领伤害参数独立于原竞技模式；远程普攻对首领伤害为基础普攻的2倍，远程主动为基础效果的95%，近战保持原伤害。生命栏旁展示对首领普攻的实际数值并提供倍率说明。所有计分均来自实际扣血。横扫预警调为固定1.35秒，阶段提升只加快招式间隔，给基础移速的近战保留撤离机会。

首领中心160像素内提供「近身护佑」：所有旅者受到的首领伤害降低20%，先减伤再消耗护盾；离开范围立即失效，小怪和陷阱伤害不变。淡绿色虚线显示范围，首领血条下显示玩家是否获得护佑。该机制不区分武器，也不影响分数归属。

## 地图选择

开局前选择地图，经典远程和近战刀战共用全部战场：

| 地图 | 地形 | 环境 |
| --- | --- | --- |
| 失落庭院 | 熟悉的断壁、岩石与石板广场 | 地刺机关、泥地 |
| 灰烬荒漠 | 开阔沙地、风蚀岩群，中央外围四根争夺掩体 | 流沙减速、地火预警后爆发 |
| 冰封遗迹 | 破碎长冰墙与错位转角通道 | 积雪减速、冰刺预警后升起 |
| 幽暗沼泽 | 分叉树根、岛状落脚点与宽主路 | 大片泥潭减速、荆棘预警后生长 |

地图与障碍每局按种子重新生成。指定地图时重开保留地图类型，选择「随机地图」则每局重新抽取；返回菜单可重新选择，刷新默认失落庭院。地图名称在战场与结算页面显示。环境沿用现有减速区和周期陷阱规则，角色数值、成长及决战规则共同使用。

近战三种刀技分别显示突进残影、环绕刀光和重斩蓄力，保留0.72–1.05秒的完整视觉与余效；动画不会额外延长动作锁或追加伤害。

## 操作

- WASD / 方向键移动。经典远程普攻自动寻找最近且视线可达的有效敌人；近战刀战使用鼠标定向、左键挥刀，按住连斩。
- 鼠标指向技能目标，Q / E / R 释放按学习顺序装备的主动技能。
- 2、4、6、8、10、12、14、15 级随机三选一，点击卡片或按 1 / 2 / 3 选择；选择期间仍能移动、攻击、释放已学技能，并可能受伤或死亡。
- 主动技能最多3个，已有主动技能仍可升级；每次升级增加生命和攻击。击败角色也会获得经验。
- Esc 暂停；失去窗口焦点或切换标签页也会暂停。
- 死亡后可以观战，通过试炼者名册点击选人，或聚焦角色行后按 Enter / 空格；窄窗口保留双列名册。也可以直接重开。

## 生存竞技规则

单局通常5–10分钟，最长12分钟。8分40秒仍无人满级时自动开启同样的决战流程，留出完整的10秒预警、180秒缩圈和收尾；12分整最终风暴覆盖全图。如果届时仍有多人存活，将同时被风暴淘汰并判平局。

前90秒角色不能互伤，怪物和陷阱正常生效。第80秒起显示全场互伤预警与10秒倒计时。之后自由交战，争夺期旅者护甲较强，决战时减伤降低。任意角色达到最高15级立刻进入决战：停止新小怪与地图经验生成，现存资源保留；随机选定可达圆心，预警10秒后在180秒内收缩至零。圈外伤害随时间上升。最后一位存活者获胜；同帧全灭显示平局。

12个出生点均匀分布在遗迹外围。相比8人版本，怪物和地图晶体的初始数量、存量上限与补充速度提高约20%，兼顾争夺密度与单局发育时间。

## 验证

```powershell
npm run verify        # 常规回归入口（推荐）
npm test              # 只跑单元测试
npm run test:browser  # 真实Chrome/Edge/Chromium输入与布局检查
npm run simulate
npm run duels
npm run melee-duels
npm run performance
node tests/boss-simulate.mjs # 四地图×双武器×三种子，24局首领战
```

`npm run verify` 串联六项检查：单元测试、双模式 60Hz 整局模拟、DOM 冒烟测试、对砍基准、性能，以及**逐秒状态哈希与改动前基线逐字节比对**。DOM 测试真实启动 `app.js`，覆盖开局、暂停、移动、近战挥刀，以及两种模式的死亡观战、胜负和平局结算、输入清理、重开和返回菜单再开局；每帧检查下一帧已注册，防止浮层报错让游戏停止刷新。任何一项失败即判定不可提交。

竞技性能默认要求P95不超过8ms，`PERFORMANCE_P95_BUDGET_MS`可设置有限正数预算，超限返回失败；verify摘要保留实际性能指标。玩法修正若确实改变状态，必须先证明差异原因并记录后，才能有意更新基线；纯重构不能用重建基线掩盖回归。

`verify`自动发现`tests/`根目录下所有`.test.js`。另有独立的`npm run test:browser`，需要本机Chrome、Edge或Chromium，可通过`BROWSER_EXECUTABLE`指定路径；没有浏览器会失败，不静默跳过。[待启用的GitHub工作流](docs/ci/verify.yml)配置了Node22/24回归、真实Chrome检查与24局首领矩阵，并保存结果；当前凭据缺少`workflow`权限，尚不能创建Actions入口。源码同步及部署情况见验证记录。

`tests/simulate.js` 支持通过命令行传入种子。规则测试使用 Node 原生测试运行器；模拟无绘制，所有角色使用同一套 AI。地图随机、技能选择和对局可用相同种子复现。

首领24局完整矩阵另行运行`node tests/boss-simulate.mjs`，覆盖四地图、两种玩家武器及三个种子。发布验证说明见[VALIDATION.md](docs/VALIDATION.md)，逐局结果见[boss-simulation-20261019.json](docs/boss-simulation-20261019.json)。

在 PowerShell 使用 `$env:SIM_HZ='60'; node tests/simulate.js sim-101` 可按浏览器的60Hz时间步长完整复测一局。

使用 `$env:GAME_MODE='melee'; $env:SIM_HZ='60'; npm run simulate` 验证近战整局；performance同样读取GAME_MODE，默认classic。

使用 `$env:GAME_MAP='desert'; $env:GAME_MODE='melee'; $env:SIM_HZ='60'; node tests/simulate.js sim-101 sim-202` 可验证指定地图，地图ID为courtyard/desert/frost/swamp，也支持random。省略GAME_MAP继续使用庭院，保留已有回归基线。

浏览器使用60Hz固定模拟与画面插值，渲染自动跟随显示器刷新率（60/120/144Hz等），实际帧率显示在战场顶部。地形预绘制、空间索引碰撞、AI寻路缓存减少每帧开销。

模块接口、分工与扩展方式见 docs/CONTRACT.md（含新增技能/怪物/模式的改动点说明）。static dist 可直接部署到任意静态站点服务，Sites 配置位于 .openai/hosting.json。
